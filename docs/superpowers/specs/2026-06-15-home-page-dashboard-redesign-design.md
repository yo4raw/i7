# トップページ ダッシュボード型フルリデザイン

- 日付: 2026-06-15
- ステータス: ユーザー承認済み（ビジュアルコンパニオンでレイアウト・カードスタイル確認済み）
- 関連 ADR: [0001](../../adr/0001-reject-glassmorphism-redesign.md)（視認性の教訓）

## 背景と問題

機能追加（衣装比較・編成組合計算・共通ブローチ等）が続いた結果、トップページ `src/pages/index.astro` の「主な機能」セクションが現状の機能を反映できていない。具体的には **衣装比較 / 編成組合計算 / 共通ブローチ** の3機能がカードに無い。

あわせて、ページ全体を現状機能に即したダッシュボード型へ刷新する（ユーザー選択: フルリデザイン）。

## 決定

`src/pages/index.astro` をダッシュボード型レイアウトで全面刷新する。カードは「シンプル＋左アクセントバー」のソリッドカード。

### デザイン原則

- 半透明・グラスは使わない。`bg-white dark:bg-slate-800` などソリッド背景＋ダークバリアントを必ずペアで指定（[0001](../../adr/0001-reject-glassmorphism-redesign.md) の視認性破棄の教訓）
- 既存のデータ取得ロジック（`fetchCardsJson` / `fetchSongsJson` / `fetchEventsCsv`）と `EventCountdown` コンポーネントは流用する

### セクション構成（上→下）

1. **ヒーロー**: サイト名「i7マネ部屋(β)」＋非公式DBの一言説明＋統計バッジを横並び（衣装枚数 / 楽曲数 / イベント件数）。現状の「サイトの目的」は3行程度に圧縮してヒーロー直下に残す
2. **開催中／次回イベント**: 既存 `EventCountdown`（liveEvents 優先、なければ upcomingEvents）をそのまま使用
3. **主な機能（カテゴリ別グリッド）**: ナビ構成に合わせ3カテゴリ
   - **データベース**: 衣装一覧（枚数表示）/ 楽曲一覧（曲数表示）/ イベント情報（件数表示）
   - **スコア計算ツール**: スコア計算 / 編成組合計算（`/score-calc/max-score-finder/`）/ 衣装比較（`/card-compare/`）
   - **登録・管理**: 所持衣装 / 共通ブローチ（`/shared-broach/`）/ 保存デッキ / ラビットノート
   - localStorage 保存に関する注記を維持
4. **衣装内訳**: レアリティ別バッジ（現状維持。機能グリッドの下に配置）
5. **下部情報（集約）**: 謝辞 / お問い合わせ / プライバシー / 免責・権利表記 — 内容は全文維持し、体裁のみ整理

各カードは左アクセントバー（インディゴ）＋見出し＋短い説明文。DB カテゴリは数値を大きく強調。全カードがリンク。

### 新規追加カード

| カード | リンク先 | カテゴリ |
|--------|---------|---------|
| 編成組合計算 | `/score-calc/max-score-finder/` | スコア計算ツール |
| 衣装比較 | `/card-compare/` | スコア計算ツール |
| 共通ブローチ | `/shared-broach/` | 登録・管理 |

## 実装範囲

- `src/pages/index.astro`: マークアップ刷新（フロントマターのデータ取得は流用）
- ADR 追加（トップ再設計）＋本 spec
- E2E（`tests/home.test.ts`）: 既存アサーション確認、新規カード（衣装比較・編成組合計算・共通ブローチ）のリンク存在を追加

## 影響範囲外（変更しない）

- ヘッダーナビ（`HeaderNav.svelte`）
- 各機能ページ本体・データ取得層・`EventCountdown` の内部
