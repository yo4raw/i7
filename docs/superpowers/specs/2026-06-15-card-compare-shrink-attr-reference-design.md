# 衣装比較 判定縮小タブに属性値由来スコアを参考表示

- 日付: 2026-06-15
- ステータス: ユーザー承認済み
- 関連 ADR: [0016](../../adr/0016-card-compare-shrink-coverage.md)（補足）

## 背景と問題

衣装比較ページの判定縮小タブは [0016](../../adr/0016-card-compare-shrink-coverage.md) でカバー秒数／カバー率（期待・最大）を比較軸に再設計した。その際、旧版チャートにあった属性値の表示が落ち、縮小タブには各衣装の属性値がまったく出ていない。

縮小衣装もデッキに編成される以上、自身の属性値でスコアに寄与する。比較は基本的にカバー率で行うが、**曲の属性が多色で拮抗している場合**は、どの縮小衣装がその曲でより多くスコアを稼ぐかが選択の参考になる。

## 決定

判定縮小タブのチャートに、各衣装の**属性値由来スコア**（`baseScore`）を参考値として表示する。

- 表示する値は曲非依存の単純合計（Shout+Beat+Melody）ではなく、**選択曲のノーツ配分を反映した属性値由来スコア** `baseScore`。スコアアップタブと同じ値で、多色拮抗曲での寄与を直接比較できるため
- **ソートには影響させない**。比較の主軸はカバー率（期待・最大）のままで、属性値由来スコアはあくまで参考表示

## UI

- `ShrinkChart.svelte` の各棒ラベルに `属性 {formatScore(baseScore)}` の行を追加する（`formatScore` による「12.3万」形式）。既存のラベル（最大/期待カバー秒数・率、発動条件、確率）に続けて表示
- チャート脚注に、属性値由来スコアが曲のノーツ配分を反映した参考値である旨を一言追記
- 詳細比較パネルは既に「属性値由来スコア」行で `baseScore` を表示しているため変更不要

## 実装範囲

- `src/components/compare/ShrinkChart.svelte`: ラベルへ属性値由来スコア行を追加、脚注追記。`formatScore` を import
- E2E（`tests/card-compare.test.ts`）は既存アサーションに影響しないが、必要なら属性スコア表示の確認を追加

## 影響範囲外（変更しない）

- スコアアップタブ（既に `baseScore` を主役表示）
- ソートロジック（`compareShrinkBy`）・カバー秒数算出（`cardStrength.ts`）
- 詳細比較パネル
