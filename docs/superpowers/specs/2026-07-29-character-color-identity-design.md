# キャラクターカラーを軸としたビジュアルアイデンティティ

- 日付: 2026-07-29
- ステータス: 設計承認済み（実装計画待ち）

## 背景

現行 UI への評価は「個性がない・どこにでもある」「地味・ツールすぎる」。実画面を確認した診断は以下のとおり。

- ホームは白カード + `border-l-4 indigo` の反復が 11 枚。社内管理ツールの外観
- 衣装一覧は機能的（行背景に衣装絵、属性の色帯、ドーナツ）だが、意味を持つ色は Shout / Beat / Melody の 3 色のみ。それ以外は indigo か gray
- サイト固有の視覚記号はヘッダーのテキストロゴのみ

つまり、**このサイトが何の世界のものかを語る視覚言語を一つも持っていない**。主色である indigo は Tailwind のデフォルトであり、アイドリッシュセブンの色ではない。

[ADR 0046](../../adr/0046-apple-design-redesign.md) はマテリアル階層・トークン・モーションを整備したが、色によるアイデンティティには踏み込んでいない。本設計はその上に色の体系を載せる。

## 決定

サイトのアイデンティティを **16 人のキャラクターカラー**に錨を打つ。

### 1. 色を 2 チャンネルに分け、色相ではなく形で分離する

| チャンネル | 意味 | 形 | 色 |
| --- | --- | --- | --- |
| 属性 | Shout / Beat / Melody | **塗りのチップ**（現行の丸バッジ） | `#ef4444` / `#22c55e` / `#3b82f6`（変更なし） |
| キャラ | 誰の衣装か | **スパイン（行頭 4px の縦線）・タブ・ドット** | キャラクターカラー 16 色 |
| 構造 | ページ・ナビ・面 | 無彩色 | 近黒 `#14151A` / 白 / グレー階調 |

属性色は赤・緑・青を占有しており、そこへ七瀬陸（赤）や二階堂大和（緑）を同じ強さで置くと、**赤い要素を見たときに「Shout なのか陸なのか」が判別できなくなる**。色相の追加では解けないため、形で分離する。

**規則: キャラ色は面を塗らない。** 線・縁・小さな点にのみ使う。これにより次の 2 点が同時に満たされる。

- 属性の赤と陸の赤が別物として読める
- 六弥ナギ（黄）や棗巳波（ベージュ）のような淡い色でも、テキストのコントラストを壊さない

キャラ色をテキスト色に使うことは禁止する。キャラ名は `gray-900` のまま置き、色はスパインが担う。

### 2. indigo を廃止し、クロームを無彩色にする

Tailwind のデフォルト色がサイトの主色である限り「個性がない」は解消しない。クロームを近黒 `#14151A` にすると、サイト内で意味を持つ色がキャラ 16 色と属性 3 色だけになり、色そのものがアイドリッシュセブンの語彙になる。

副次的な利点として、八乙女楽（グレー）や棗巳波（ベージュ）のような彩度の低い色は白背景では弱いが、近黒の上では 16 色すべてが明確に分離する。実測値は §4 に示す。

**リンク・見出し・ボタンも無彩色にする。** `indigo` は 179 箇所で使われており、うち 106 箇所は `text-indigo-*`、すなわちリンクと見出しの色である。クロームだけを無彩色にしても、サイトの主色はデフォルト色のまま残る。

- リンク: 近黒 + 下線
- 見出し: 近黒
- 主ボタン: 近黒の塗り
- フォーカスリング: 近黒

これにより「意味を持つ色はキャラ 16 色と属性 3 色だけ」という原則が例外なく成立する。

### 3. 署名要素: 16 色バーを 3 つのスケールで反復する

同じ 16 色の並びを異なるスケールで繰り返すこと自体を、サイトの署名とする。

| スケール | 場所 | 役割 |
| --- | --- | --- |
| 3px の線 | ヘッダー下端（全ページ） | 識別のみ。ロゴに相当 |
| 名前つきチップ列 | 衣装一覧のキャラ絞り込み | フィルタとして機能する（既存 `CardFilterChips` に色を与える。構造は変えない） |
| 大判 | ホームのヒーロー | 各セグメントがそのキャラの衣装一覧へのリンク |

**ユニット（IDOLiSH7 / TRIGGER / Re:vale / ŹOOĻ）で区切る。** これは装飾ではない。16 色にはピンク系 3・緑系 2・紺 2・無彩色に近い色 2 が含まれ、単純に並べると判別できない。一方ユニット内では色がよく分離している（IDOLiSH7 の 7 色は赤橙黄緑水青紫でほぼ虹）。区切りが色システムを読める状態にしている。

一覧のフィルタでは各チップにキャラ名を表示する。色だけのチップ 16 個は、どの色が誰かを知らない利用者には使えず、支援技術からも読めない。**色は索引、名前はラベル**という役割分担を崩さない。

衣装一覧のキャラフィルタは `src/components/CardList.svelte` の `CardFilterChips` として既に存在し、`CHARACTER_GROUPS` によるユニット分けも済んでいる。ここは新規に作らず、既存チップにキャラ色を与える。選択中はキャラ色を点灯させ、未選択は無彩色に落とす。

大きな色面はホームのヒーローのみとする。それ以外のページに色面を追加しない。

### 4. キャラクターカラーの色値

公開されている**公式カラーコードは存在しない**。定着しているのは色名のみ。以下の HEX は色名から本設計で校正した候補値であり、公式値ではない。

出典（色名）: [オシコレ](https://oshicolle.net/archives/405) / [にじめん](https://nijimen.kusuguru.co.jp/topics/623709)

| IDOLiSH7 | 二階堂大和 | 明るい緑 | `#43B75D` | 属性 Beat と近い。形で分離 |
| IDOLiSH7 | 和泉三月 | 橙 | `#F08322` | |
| IDOLiSH7 | 四葉環 | 水色 | `#56C5E8` | |

| IDOLiSH7 | 六弥ナギ | 黄 | `#F5C518` | 白地では弱い |
| IDOLiSH7 | 七瀬陸 | 赤 | `#E4373B` | 属性 Shout と近い。形で分離 |
| TRIGGER | 八乙女楽 | グレー | `#9AA3AD` | 白地では弱い |
| TRIGGER | 九条天 | 淡ピンク | `#F2A7C3` | |
| TRIGGER | 十龍之介 | 紺 | `#5878A6` | **原作では一織と同じ「紺」。分離のため本設計で彩度を下げた創作値** |
| Re:vale | 百 | 蛍光ピンク | `#FF3D8B` | |
| Re:vale | 千 | 蛍光黄緑 | `#C3E829` | |
| ŹOOĻ | 亥清悠 | ミントグリーン | `#6FDCC0` | |
| ŹOOĻ | 狗丸トウマ | 暗い赤 | `#C0353D` | 近黒上で見えるよう明度を上げた |
| ŹOOĻ | 棗巳波 | ベージュ | `#D8C3A0` | 白地では弱い |
| ŹOOĻ | 御堂虎於 | 薄い赤紫 | `#C77FC0` | |

**コントラスト実測（WCAG 相対輝度）**

16 色すべてが近黒 `#14151A` に対して 3:1（WCAG 1.4.11 非テキストコントラスト）を満たす。最小は和泉一織の 3.15、次いで狗丸トウマの 3.31 で、この 2 色は余裕が小さい。

一方、白 `#ffffff` に対する最小は千の 1.41（ほかに亥清悠 1.66、棗巳波 1.72、六弥ナギ 1.63、九条天 1.89、四葉環 1.99 が 2:1 未満）。**16 色は白背景では成立せず、近黒クロームが前提条件である**ことが実測で裏付けられた。

色値の単一情報源は `src/lib/constants.ts` の `CHARACTER_HEX` とする（`ATTR_HEX` と同じ扱い）。`global.css` の `@theme` に複製する場合は、`ATTR_HEX` と同様に「変更時は両方を更新する」旨のコメントを添える。

### 5. 数字・欧文専用フォントを導入する

CJK はシステムフォントスタックを維持する（ADR 0046 §5 を踏襲）。変更するのは数字と欧文のみ。

- 書体: **Barlow Semi Condensed**（400 / 600 / 700）
- 適用範囲: 数値表示（スコア・属性値・パーセント・レベル）とラテン文字。日本語本文には適用しない
- 配信: セルフホスト。数字 + 基本ラテン + 約物にサブセットし、`woff2` で 15〜25KB を目安とする
- 選定理由: 低コントラストのグロテスクで日本語ゴシックとリズムが合う。字幅が狭く、6〜7 桁のスコアが密なテーブルセルに収まる（意匠だけでなく情報量の実利がある）

これは ADR 0046 §5「カスタム Web フォントは導入しない」に対する限定的な例外である。

## 適用範囲

**色を出す場所**

- 衣装一覧の行スパイン
- 衣装詳細（キャラクター行のドット）
- デッキスロット（スロット縁のスパイン）
- キャラクターフィルタ
- ヘッダーおよびホームの 16 色バー

**衣装比較のチャートには適用しない。** 当初は系列色に使う想定だったが、`src/components/compare/ShrinkChart.svelte` の系列枠線は既に属性色（`ATTR_HEX`）が占有している。ここへキャラ色を重ねると「属性＝塗り／キャラ＝線」の分離規則を自ら破ることになるため、対象から外す。

**色を出さない場所**

- 本文の背景（[ADR 0046](../../adr/0046-apple-design-redesign.md) の `surface-card` = 完全不透明を維持）
- テキスト色
- 上記以外の大きな色面

**変更するファイル（主なもの）**

- `src/lib/constants.ts`: `CHARACTER_HEX` 追加
- `src/styles/global.css`: `material-chrome` を indigo から無彩色へ。キャラ色トークンを `@theme` へ追加
- `src/components/HeaderNav.svelte`: 16 色バー
- `src/components/CardList.svelte` / `CardFilterChips`: 行スパイン、既存キャラチップへの着色
- `src/pages/index.astro`: ヒーロー

## 検証

[ADR 0001](../../adr/0001-reject-glassmorphism-redesign.md) の教訓に従う。

- 承認はスタイル適用済みの**実データ画面（衣装一覧・スコア計算）**で取る。ミニモックでは承認しない
- デスクトップ幅とモバイル幅の両方を確認する
- キャラ色を使った要素のコントラストを実測する。テキストに対するキャラ色の使用がないことを確認する
- Barlow Semi Condensed が `font-variant-numeric: tabular-nums` に対応するかを実機で確認する（対応しない場合は等幅の代替手段を検討する）

## 検討した代替案

- **グループ 4 色（IDOLiSH7 / TRIGGER / Re:vale / ŹOOĻ）を主役にする**: 変更規模が小さく安全だが、固有性が限定的で「個性がない」への回答にならない
- **1 画面 1 キャラ色（衣装詳細・キャラ絞り込み時のみ色が出る）**: 混乱リスクは最小だが、主戦場である一覧画面が現状のまま変わらず、「地味」が残る
- **indigo を継承したままキャラ 16 色を追加する**: ブランド継続性は保たれるが、サイトの主色がデフォルト色のままとなり、色がアイドリッシュセブンの語彙にならない
- **キャラ色を塗り（面）で使う**: 視認性が高く目を引くが、属性色との衝突が解けず、淡色キャラでコントラストが破綻する（ADR 0001 の再演）
