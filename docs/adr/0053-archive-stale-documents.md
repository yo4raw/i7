# 0053 陳腐化した要件定義書・旧スプレッドシート仕様を docs/archive/ へ隔離する

- ステータス: 承認
- 日付: 2026-08-21

## 文脈

リポジトリのドキュメントを点検したところ、現行仕様と食い違う文書が実装の参照先に混在していた。

- `requirements_definition.md`（ルート直下、344 行、最終更新 2026-04-24）は**存在しない画面を記述している**。画面パスが `/card/[id]`（実際は `/cards/[id]`）、`/scoreup`（実装されていない）、レイアウト方針が「フッター: なし（シンプル設計）」（実際はフッターにエクスポート/インポート UI がある）など。20 ページ中 5 ページ分しか記述がなく、「今後の拡張計画」に挙がった項目も着手されていない。ルート直下にあり `CLAUDE.md` と並んで見えるため、人・エージェントとも現行仕様と誤認しやすい。
- スプレッドシート仕様が `v1.0.5` / `v1.0.6 調査メモ` / `v1.0.7` の 3 世代で `docs/` 直下に並存していた。ADR 0040 でスコア計算の検証は **v1.0.7 を正とする**と決定済みだが、ファイルの並びからはどれが正か読み取れない。

一方で、これらを単純に削除するのは適切でない。

- `docs/spreadsheet-spec-v1.0.7.md` は `v1.0.5` を **「本書のベースライン」として明示的に依拠**し、§15 に両者の差分を記録している。v1.0.5 は単なる旧版ではなく、別コピー（id `1St4Hf609y9FobAn6-UjDIbkzDedo4Bssl5HT7PalFRk`）を対象とした独立の調査記録であり、現行仕様の根拠の一部をなす。
- `v1.0.6 調査メモ` も v1.0.7 が各シートの gid の出典として引いている。

## 決定

1. **`docs/archive/` を新設し、現行仕様ではない文書をそこへ隔離する**。削除はしない。判断基準は「実装に追随させる意思がなく、かつ現行仕様と食い違う可能性がある文書」。
2. 対象は `requirements_definition.md`、`spreadsheet-spec-v1.0.5.md`、`spreadsheet-v1.0.6-investigation.md` の 3 件。
3. **各文書の冒頭に、現行仕様ではない旨・食い違う具体例・正となる参照先を注記する**。ディレクトリ名だけでは中身を開いた人に伝わらないため。
4. **現行文書からの参照はアーカイブ先へ追随させる**。`docs/spreadsheet-spec-v1.0.7.md` 内の 6 箇所のリンクを `docs/archive/` 配下へ書き換えた。参照が切れないことをアーカイブの前提条件とする。
5. **現行の仕様は `CLAUDE.md` と `docs/adr/` を正とする**。要件定義書は今後メンテナンスしない。

## 検討した代替案

- **`requirements_definition.md` を実装に合わせて全面改訂する**: 正確な要件定義書が手に入るが、20 ページ分の画面設計・機能一覧・システム構成は `CLAUDE.md` と大きく重複する。2 つの文書を同期し続ける負担に見合わず、片方が陳腐化して再び同じ問題を起こす。不採用。
- **`requirements_definition.md` を削除する**: 現行仕様は `CLAUDE.md` と ADR で網羅されており、初期構想は git 履歴に残る。ただしルート直下の文書を消すと「初期に何を作ろうとしていたか」への到達コストが上がる。隔離で目的（誤認の防止）は達せられるため不採用。
- **移動せず、冒頭に注記だけ入れる**: 参照リンクが一切壊れない利点があるが、ルート直下・`docs/` 直下という位置そのものが「現行文書」という信号を発しており、注記を読む前に誤認される。不採用。
- **`docs/README.md` に索引を新設して整理する**: 80 件超のファイルの見通しは良くなるが、索引自体が陳腐化する新たな維持対象になる。ADR は既に `docs/adr/README.md` に索引があり、`specs` / `plans` は日付順に並ぶ point-in-time の記録なので索引の価値が薄い。今回は不採用。

## 影響

- 新設: `docs/archive/`（3 ファイル）
- 移動: `requirements_definition.md` → `docs/archive/`、`docs/spreadsheet-spec-v1.0.5.md` → `docs/archive/`、`docs/spreadsheet-v1.0.6-investigation.md` → `docs/archive/`
- 更新: `docs/spreadsheet-spec-v1.0.7.md` の参照リンク 6 箇所
- `docs/superpowers/plans` / `specs` 配下の 5 文書が旧パスへのリンクを保持したままになる。これらは意思決定時点の記録（point-in-time artifact）であり、当時の記述を書き換えない方針のため追随させない。
- `docs/superpowers/plans` / `specs` に残る「Astro 6」表記（19 ファイル、実体は 7.0.3）も同じ理由で修正しない。
