# 0073 衣装比較の棒グラフと特効バッジの配色を見直す

- ステータス: 承認
- 日付: 2026-09-03

## 文脈

衣装比較画面の 2 つの棒グラフ（スコアアップ・判定縮小）で、属性値由来スコアのバーに `chrome-ink-soft` (#2A2C33) を使っていた。ADR 0047 で構造の配色を無彩色に寄せた際、チャートのインクとしてクロームと同じ近黒を選んだためである。

この選択には 2 つの問題があった。

- 属性値由来スコアはバー全体の 7 割前後を占める。その最大面積が近黒で塗られるため画面全体が重く、黒の面が並ぶ見た目になっていた
- 衣装ごとに差が出るのはスキル部（オレンジ）であり、属性値由来スコアは衣装間でほとんど変わらない土台である。比較の主役ではない部分が視覚的に最も強く、情報の重み付けが逆転していた

あわせて、イベント特効の段階バッジは金が `yellow-100/800/400`、銅が `amber-100/800/400` だった。Tailwind の yellow と amber は隣接する色相で明度も近く、同じ一覧に並ぶと判別できない。バッジは衣装比較だけでなく衣装一覧・スコア計算・編成組合計算など 9 コンポーネントで共有しているため、影響はサイト全体に及んでいた。

判定縮小の凡例に「右（紫）」という記述が残っていた。過去の配色の名残で、実際のバーは近黒であり実挙動と食い違っていた。

## 決定

### 1. 棒グラフの土台を薄いグレーに落とす

属性値由来スコアのバーを `chrome-ink-soft` から `gray-300` (#d1d5db) へ変更し、スキル期待値を `amber-400` から `amber-500` (#f59e0b) へ一段濃くする。目減り分の `amber-200` は据え置く。

土台を背景側へ退かせ、比較の主役であるスキル部を前に出す。情報の重み付けを視覚的な強さと一致させるための変更である。

無彩色の階調内に収まるため ADR 0047 の 3 チャンネル規約（属性・キャラ・構造）には抵触しない。`--color-chrome-ink-soft` トークン自体はボタンなど他 10 コンポーネントが使っているため変更しない。差し替えるのは `ScoreUpChart.svelte` と `ShrinkChart.svelte` のクラスのみとする。

判定縮小の属性値バーは幅 16px と細いが、白背景に対して `gray-300` でも十分読める（実機で確認済み）。参考値であることとも整合するため、こちらも同じ階調に揃える。

### 2. 特効バッジを色相と塗りの重さの両方で描き分ける

| 段 | 塗り | 文字 | 枠 |
| ---- | ---- | ---- | ---- |
| 金 | `bg-yellow-400` | `text-yellow-950` | `border-yellow-500` |
| 銀 | `bg-gray-200` | `text-gray-700` | `border-gray-400` |
| 銅 | `bg-[#FDF2E9]` | `text-[#7A4520]` | `border-[#B06A3B]` |

色相を離すだけでなく、塗りの濃さを 金 > 銀 > 銅 の順に段階付ける。特効の強さの順序が色の記憶に頼らず伝わり、色覚特性の影響も受けにくい。銅色は Tailwind のパレットに該当色がないため任意値で指定する。

テキストのみで段階を示す `labelClass` も、金を `text-yellow-600` から `text-yellow-700` へ、銅を `text-amber-700` から `text-[#A25E2E]` へ変更する。前者は白背景でコントラストが不足していた。

塗り付きバッジの枠には彩度の高い `#B06A3B` を使うが、テキストのみの `labelClass` はこれより暗い `#A25E2E` とする。`#B06A3B` は白背景に対して 4.26:1 で、12px 太字（WCAG の large text に当たらない）では AA の 4.5:1 に届かないためである。改訂後の各段のコントラスト比は白背景のテキストで金 4.92:1 / 銅 5.03:1、塗りの上のバッジ文字で金 9.52:1 / 銀 8.33:1 / 銅 7.06:1 といずれも AA を満たす。

ADR 0047 の適用範囲では「イベント特効の段階（金銀銅）」を 3 チャンネル規約の対象外として色相の保持を認めている。本 ADR はその対象外枠の中で具体色を改訂するものであり、対象外表そのものは変更しない。

### 3. 判定縮小の凡例を実挙動に合わせる

「右（紫）」を「右（グレー）」に修正する。

## 検討した代替案

- **属性値由来スコアを中間グレー (`gray-400`) に留める**: 黒の重さは解消するが土台の存在感が残り、主役がスキル部へ移らない。最小変更ではあるが、問題の半分しか解けないため採らなかった
- **属性値由来スコアを青みのある淡色 (slate 系) にしてオレンジと寒暖で対比させる**: 2 系統の区別は最も明確になるが、わずかとはいえ色相が入るため ADR 0047 の対象外表に一行足す必要が生じる。無彩色のまま十分な分離が得られたため見送った
- **特効バッジの塗りの重さを揃えて色相だけ離す**: 現行の見た目からの変化は小さいが、強さの順序が色でしか伝わらない。段階を持つ指標である以上、視覚的な強さも段階付けるほうが情報構造に合う
