# 0034. llms.txt の追加

- ステータス: 承認
- 日付: 2026-06-30

## 背景

LLM／AI エージェントがサイトの概要と主要ページを把握しやすいよう、[llms.txt 標準](https://llmstxt.org/) のファイルをルートで配信したい。当サイトは衣装/楽曲/イベントの詳細ページが 2700 件超あり、HTML を逐次クロールさせるより、サイトの目的と主要導線を簡潔にまとめた索引を提供するほうが効率的かつ意図が伝わりやすい。

## 決定

`public/llms.txt` に手書きの静的ファイルを配置し、`https://i7.yo4raw.com/llms.txt` で配信する。

- 形式は llms.txt 標準（H1 タイトル → blockquote 要約 → 補足箇条書き → H2 リンクセクション）に準拠する。
- 記述言語は日本語とする。サイト本体・`PAGE_DESCRIPTIONS`（`src/lib/seo.ts`）がすべて日本語であり、表現を一致させ二重管理を避けるため。各リンクの説明文は `PAGE_DESCRIPTIONS` の文言を流用する。
- セクションは「データベース」「プレイヤー向けツール」「サイト情報」「Optional」の4つ。
- 2700 件超の衣装/楽曲/イベント詳細は個別に列挙せず、各一覧ページと、`Optional` セクションのサイトマップ（`/sitemap-index.xml`）へのリンクに集約する。ファイルの肥大化とノイズを避けるため。

## 検討した代替案

- **ビルド時に動的生成（`src/pages/llms.txt.ts` 等で全カード/楽曲/イベントを列挙）**: 網羅性は高いが 2700 行超の巨大ファイルとなりノイズが多い。`getStaticPaths` 同様にデータフェッチが必要で保守コストも増える。索引としての価値が低いため不採用。
- **`llms-full.txt`（全コンテンツの全文版）の併設**: 全衣装データを含めると巨大になり、マスターデータはクライアントフェッチのためビルド時に静的展開する仕組みが別途必要。費用対効果が低く現時点では不採用。
- **記述言語を英語にする**: 海外 LLM ツールのパースには有利だが、サイト本文・既存の説明文がすべて日本語であり表記がズレる。日本語ユーザー向けゲームのファンサイトであることからも日本語を採用。

## 影響

- `public/llms.txt` を新規追加。ビルド時に `dist/llms.txt` へコピーされる。
- robots.txt / `_headers` の変更は不要（`Disallow: /*?` はクエリ付き URL のみが対象で `/llms.txt` には影響しない。`.txt` は既定で `text/plain` 配信）。
- ページや主要機能を追加・改廃した際は `public/llms.txt` のリンクと説明も更新する。
