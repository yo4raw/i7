# 0024: 衣装比較 詳細パネルにスコア分布（二項分布）を追加

- 日付: 2026-06-18
- ステータス: 承認

## 背景

[0018](0018-card-compare-scoreup-max-overlay.md) で詳細パネルに期待値・最大値を併記したが、最大値は「全発動機会で発動成功」した理論上限であり、発動回数が多い衣装ほど到達確率が極小になる。期待・最大の2点だけでは「どれだけ安定して稼げるか」「上振れがどれだけ起こりやすいか」が見えず、比較判断がしにくい。

## 決定

詳細比較パネルに各衣装の**スコア（縮小はカバー秒数）の分布**を重ね合わせ密度曲線で描画する。

- スキル発動成功回数 `K ~ Binomial(n=最大発動回数, p=発動率)` の二項分布を**解析的に厳密計算**（モンテカルロ不使用）
- 横軸は**絶対スコア軸**（縮小はカバー秒数）。同種衣装の `[最小ベース〜最大]` を共有スケールに最大4枚を重ねる
- しきい値は「スキル上乗せ分（発動成功分）に対する %」。衣装ごとに**独立した縦線**を引き、各線を個別にドラッグして % を変更でき、`P(≥)` を個別表示する
- 全線を同じ % に一括セットする単一スライダーを併設する（初期位置合わせ・キーボード操作用）
- スコアアップ衣装と縮小衣装が混在選択された場合は、単位が異なるためチャートを2つ（スコア用・秒数用）に分割する
- 1枚あたりの分布計算は純粋関数 `src/lib/score/cardDistribution.ts` に切り出し、Vitest で単体テストする
- ランキングチャートは現状維持。状態の永続化はしない

## 検討した代替案

- **正規化軸（しきい値線1本・共通）** — スライダーと素直に対応するが絶対スコアの高低が見えないため不採用
- **単一の絶対スコアしきい値線** — 線1本で単純だが「上乗せ分%」での上振れ比較が弱いため不採用
- **確率バーのみ（分布を描かない）** — ばらつきが見えず本機能の目的を満たさないため不採用
- **モンテカルロの流用** — 単純な二項分布で厳密計算でき、MC は近似かつ低速なため不採用

設計の詳細は [docs/superpowers/specs/2026-06-18-card-compare-distribution-design.md](../superpowers/specs/2026-06-18-card-compare-distribution-design.md) を参照。
