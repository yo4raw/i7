# 0057 インデックス対象を独自性のあるページへ絞る

- ステータス: 承認
- 日付: 2026-08-21

## 文脈

Google Search Console で、**サイトの全ページが「クロール済み - インデックス未登録」**になっていた。技術的な阻害要因は無いことを実測で確認済み。

- `noindex` メタ・`X-Robots-Tag` ヘッダともに無し
- canonical は全ページで自 URL を指しており、sitemap の URL とも一致
- Googlebot の UA で HTTP 200・全文が返る（トップ 37KB / 衣装詳細 21KB）
- `workers.dev` 等での同一コンテンツの重複露出は無し
- sitemap は Search Console に登録済み

つまり技術面ではなく、**サイト単位の評価**の問題である。実際に検索しても `i7.yo4raw.com` は 1 件も出てこず、代わりにデータ元の `i7.step-on-dream.net` が同じ領域を多数のページで押さえている。

Google から見た構図は次のとおり。

- サイトは 2026-04-09 公開で約 4.5 か月、被リンクがほぼ無い無名ドメイン
- 3223 ページのうち **2824 ページ（88%）が衣装詳細**で、その元データは既にインデックス済みの別サイト由来
- 衣装詳細 1 ページあたりの独自テキストは中央値 515 文字（最小 356 / 最大 695）と薄く、全ページが同一テンプレート

無名ドメインが 3223 ページを申告すると評価が薄く広がり、どのページにもインデックスの枠が回らない。

一方で、独自コンテンツ量を実測すると差は明確だった。

| ページ | 独自テキスト量 | データ元サイトに同等物 |
| --- | --- | --- |
| スコア計算 仕様解説 | 14,554 文字 | **無い（完全独自）** |
| 編成組合計算 | 8,258 文字 | 無い |
| イベント一覧 | 11,351 文字 | ある |
| 楽曲一覧 | 21,875 文字 | ある |
| 衣装一覧 | 23,297 文字 | ある |
| 衣装詳細 ×2824 | 各 515 文字 | **ある（派生元）** |

## 決定

**インデックス対象を、独自性があり検索から入る価値のあるページへ絞る。** 対象ページには `noindex,follow` を付け、同時に sitemap からも外す。

| 除外対象 | 件数 | 理由 |
| --- | --- | --- |
| 衣装詳細 `/cards/{id}/` | 2824 | 元データが既にインデックス済みの別サイト由来。独自テキストが中央値 515 文字と薄く、全件が同一テンプレート |
| イベント共有ページ `/events/{id}/share/{ssr,ur}/` | 150 | SNS 共有用のレアリティ別抜粋。イベント詳細と内容が重複する |
| 個人データページ `/mycard/` `/decks/` `/rabbit-note/` `/shared-broach/` | 4 | localStorage 依存で静的 HTML が実質空（144〜929 文字）。検索から入る価値が無い |

結果として sitemap は **3223 件 → 249 件**になる。

### `noindex` は `follow` を付け、robots.txt ではブロックしない

`noindex,follow` とし、リンクは辿らせる。**robots.txt でブロックしてはならない** — クロールを止めると Google が `noindex` タグ自体を読めず、意図が伝わらないため。

### 除外はページ側の `noindex` と sitemap の `filter` を必ず対で設定する

片方だけだと「sitemap で申告しているのに `noindex`」という矛盾したシグナルになる。`BaseLayout.astro` の `noindex` prop と `astro.config.mjs` の `sitemap.filter` を対で更新すること。E2E（`tests/seo.test.ts`）で両者の整合を検証する。

### 衣装詳細はページとしては維持する

`noindex` にするだけで、ページ自体は残す。SNS 共有・サイト内リンク・ユーザーのブックマークはすべて従来どおり機能する（OGP / Twitter Card は `noindex` の影響を受けない）。

## 検討した代替案

### 全 3223 ページのインデックスを目指す（却下）

被リンクを積んでドメインの評価が上がれば理論上は可能だが、無名ドメインが 88% を占める派生コンテンツで評価を得るのは現実的でない。まず独自性のあるページでインデックスと流入を確立し、そこから段階的に開放するほうが早い。

### 衣装詳細に独自コンテンツを足して差別化する（見送り）

関連衣装の相互リンクや解説を足せば独自性は上がるが、2824 ページ分を用意する現実的な手段が無い。将来、自動生成でない付加価値（スコア計算に基づく評価など）を載せられるようになった時点で再検討する。

### robots.txt でクロールごと止める（却下）

クロールを止めると `noindex` タグが読まれず、既にインデックスされているページを削除できない。またサイト内リンク経由の評価伝達も断たれる。

## 影響

- `src/layouts/BaseLayout.astro` に `noindex` prop を追加。
- `src/pages/cards/[id].astro`、`src/pages/events/[id]/share/{ssr,ur}.astro`、`src/pages/{mycard,decks,rabbit-note,shared-broach}/index.astro` に `noindex` を付与。
- `astro.config.mjs` の `sitemap.filter` で同じ URL 群を除外。
- `tests/seo.test.ts` に `noindex` と sitemap の整合を検証するテストを追加。

## 事後の実測（2026-08-31）

本 ADR の実装（#421）をリリースした 10 日後、Search Console で反映状況を確認したところ、**「文脈」に記した前提が不正確だった**ことが判明した。決定そのものは覆さないが、以降の判断を誤らせないために記録する。

### Google が認識しているのはサイト全体で 4 ページだけだった

「サイトの全ページが『クロール済み - インデックス未登録』」と書いたが、正しくは**「Google が知っている 4 ページが未登録」**であり、残る 3,000 ページ超はそもそもクロールされていなかった。カバレッジレポートの実測値は以下のとおり（プロパティ `sc-domain:i7.yo4raw.com`、インデックス登録済み **0** 件）。

| URL | 前回クロール |
| --- | --- |
| `/cards/3782/` | 2026-06-30 |
| `/cards/` | 2026-04-24 |
| `/` | 2026-04-22 |
| `/score-calc/` | 2026-04-22 |

URL 検査でも、`/score-calc/spec/`（独自テキスト 14,554 文字の最重要ページ）を含むツールページの大半が「URL が Google に認識されていません」= 未クロールだった。技術的な阻害要因が無いことは改めて確認している（クロール許可 = はい / 取得 = 成功 / インデックス登録を許可 = はい / canonical = 自 URL）。

### sitemap は 2 か月間読み直されていなかった

送信済み sitemap の最終読み込み日は 2026-06-27 のままで、検出ページ数も **3,165 件**（縮小前の値）だった。#421 をリリースしても Google 側は古い sitemap を保持したままだったため、Search Console から再送信した。なお本番の `sitemap-0.xml` の実件数は **246 件**である（本文の 249 件は実装時の見込み値）。

### 含意: ボトルネックは申告ページ数ではなくクロール量

3,223 件を申告して 4 件しか取得されていない以上、「申告が多すぎて評価が薄く広がる」という診断は主因ではない。実態は**このドメインに割り当てられているクロール量がほぼゼロ**ということであり、申告を 246 件に絞ってもクロール量そのものは増えない。

したがって本 ADR の施策は前提条件を整える意味しか持たず、状況を動かすのは下記「残る課題」に挙げた**被リンクの獲得**と**ツールページの静的コンテンツ拡充**の 2 点である。両者の優先度を引き上げる。なお静的コンテンツについては ADR 0058 で `ToolGuide.astro` による解説セクションを追加済み。

## `/privacy/`（プライバシーポリシー）の扱い（2026-09-01 追記）

ADR 0064（端末間同期）で追加したプライバシーポリシーページ `/privacy/` は、本 ADR の除外リストに該当しない。法的ページは検索から到達できる必要があるため `noindex` にせず、インデックス対象のままとする。sitemap 側も対応不要 — `astro.config.mjs` の `sitemap.filter` は本 ADR の除外リストに挙げたページのみを除く方式（除外リスト方式）であり、リストに載らないページは既定で sitemap に含まれるため、`/privacy/` を追加するための設定変更は発生しない。

## 残る課題（本 ADR のスコープ外）

- **ツールページ自体の静的コンテンツが薄い。** `/score-calc/`（118 文字）・`/card-compare/`（210 文字）・`/point-calc/`（200 文字）はクライアントサイドアプリのため静的 HTML がほぼ空。このサイトの独自価値の中心でありながら、現状ではインデックスされにくい。各ツールに使い方・計算根拠などの静的な解説を載せる必要がある。
- **被リンクが無い。** 無名ドメインの信頼は外部リンクでしか付かない。ツールまとめサイトへの掲載や X での告知が本質的な解決になる。
- 衣装詳細 1236 件（43.8%）はサイト内のどこからもリンクされていない。`noindex` にした以上優先度は下がるが、将来インデックスを開放する際には解消が必要。
