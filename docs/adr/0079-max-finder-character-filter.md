# 0079 編成組合計算で算出対象キャラクターを絞り込めるようにする

- ステータス: 承認
- 日付: 2026-09-06

## 文脈

編成組合計算（[0029](0029-max-finder-event-select.md)）の探索候補は「選んだハイスコアイベントの金 / 銀特効 UR 衣装すべて」に固定されていた。候補が多い記念日 / 周年系イベントでは組合せが数百万通りに膨らみ、所持衣装で絞る以外に探索を狭める手段がなかった。

また、グループ限定の固有ブローチは同グループ編成でなくても発動扱いで加算している（[0072](0072-assume-same-group-broach.md)）。同グループだけで組んだときの実スコアを知りたい場合、利用者は結果から混成編成を目で除くしかなかった。

衣装一覧にはキャラクター単位・グループ単位（IDOLiSH7 / TRIGGER / Re:vale / ŹOOĻ）で絞り込むチップ UI が既にある。

## 決定

**編成組合計算に、衣装一覧と同じキャラクターフィルタ（グループ一括選択付き）を置き、選んだキャラクターの特効衣装だけを探索候補にする。**

- 何も選ばなければ従来どおり全キャラクターが対象。選択は候補枚数・組合せ数の表示にも反映する
- センター・メンバー 4 枠だけでなくフレンド枠の候補も同じ絞り込みを受ける。「算出対象」を枠ごとに分ける UI は置かない
- 選択は保存しない（所持衣装で検索などの探索オプションと同じ扱い）。イベント選択だけを保存する現状は変えない
- チップの見た目・グループ定義は衣装一覧と共通化し、両画面で同じ配色・並びにする
- ツール解説（[0058](0058-tool-page-static-guide.md)）に絞り込みの説明を加える

## 検討した代替案

### フレンド枠は絞り込みの対象外にする（却下）

フレンドは他プレイヤーから借りるため、自分のグループ縛りとは無関係に選べるという考え方。ただし「同グループ編成での実スコアを見る」用途ではフレンドも同グループにしたいことが多く、枠ごとに切り替える UI を足すほどの需要は見えていない。必要になれば枠ごとの切替を後から加える。

### 選択を localStorage に保存する（却下）

イベント選択と同様に保存する案。キャラクター絞り込みは探索のたびに変えることが多く、前回の選択が残っていると「候補が少ない」原因に気づきにくい。他の探索オプションが保存されていないこととも揃える。

### 現状維持（却下）

所持衣装で検索だけで絞る案。所持登録をしていない利用者には効かず、同グループ編成の試算という用途にも応えられない。
