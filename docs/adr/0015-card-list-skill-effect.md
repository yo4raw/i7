# 0015. 衣装一覧のリスト表示に最上位レベルのスキル効果文を表示する

- ステータス: 承認
- 日付: 2026-06-15

## 背景

衣装一覧のリスト表示（デスクトップ表・モバイルのカード型）は、スキル種別ラベル（`ap_skill_type`）しか表示しておらず（モバイルはスキル自体非表示）、実際の効果（発動条件・確率・効果量）を見るには各衣装の詳細ページを開く必要があった。一覧でスキル内容を比較したいニーズがある。

## 決定

リスト表示に、スキルの**最上位レベルの効果文**を併記する。

- 効果文は詳細ページと同じ `formatSkillEffect` で生成し、レベル番号（`Lv5` 等）を前置する。
- 表示レベルは「数値（count/per/value）がいずれも 0 より大きい最上位レベル」を採用する。Lv5 が無い SSR や、Lv5 が未登録（スプレッドシート上で 0 埋め）の新規衣装は Lv4 以下へフォールバックし、登録済みの最上位（新規カードでは Lv1 のこともある）を表示する。
- 効果文を持たない種別（スキルなし・判定補助系で `formatSkillEffect` が `'-'` を返すもの）や全レベル未登録の場合は効果文を出さず、種別ラベルのみ表示する。
- デスクトップ表は「スキル」列を2段（種別ラベル＋効果文）に、モバイルは属性値の下にスキルブロックを新設する。

ロジックは `src/lib/score/skillFormatter.ts` に `getMaxApSkillLevel` / `formatSkillEffectMax` として集約し、両コンポーネントから利用する。

## 検討した代替案

- **Lv5 固定表示**: SSR（Lv5 無し）や未登録新規衣装で「0回毎に0％…0UP」と表示されてしまうため不採用。最上位レベルのフォールバックを採用。
- **レベル番号を出さない**: Lv5 か Lv4 か（あるいは Lv1 か）が区別できないため、レベル番号を前置する。
- **新規列を追加**: 既に列数の多いテーブルがさらに横長になるため、既存「スキル」列に2段で収める。

## 影響

- `src/lib/score/skillFormatter.ts`（ヘルパー追加）、`src/components/cards/CardTableRow.svelte`・`CardMobileCard.svelte`（表示追加）、`tests/unit/score/skillFormatter.test.ts`（ヘルパーのテスト追加）。
- スコア計算・データ取得ロジックには影響しない（表示のみ）。
