# 0047 キャラクターカラーを軸としたビジュアルアイデンティティ

- ステータス: 承認
- 日付: 2026-07-29

## 文脈

現行 UI への評価は「個性がない・どこにでもある」「地味・ツールすぎる」。ホームは白カード + `border-l-4 indigo` の反復で社内管理ツールの外観、衣装一覧は意味を持つ色が属性 3 色のみで、サイト固有の視覚記号はヘッダーのテキストロゴだけだった。主色である indigo は Tailwind のデフォルト色であり、アイドリッシュセブンの色ではない。

[ADR 0046](0046-apple-design-redesign.md) はマテリアル階層・トークン・モーションを整備したが、色によるアイデンティティには踏み込んでいない。本 ADR はその上に色の体系を載せる決定を記録する。詳細設計は `docs/superpowers/specs/2026-07-29-character-color-identity-design.md` を参照。

## 決定

サイトのアイデンティティを **16 人のキャラクターカラー**に錨を打つ。

### 1. 色を 3 チャンネルに分け、色相ではなく形とチャンネルで分離する

| チャンネル | 意味 | 形 | 色 |
| --- | --- | --- | --- |
| 属性 | Shout / Beat / Melody | 塗りのチップ（既存の丸バッジ） | `#ef4444` / `#22c55e` / `#3b82f6`（変更なし） |
| キャラ | 誰の衣装か | スパイン（行頭の縦線）・タブ・ドット | キャラクターカラー 16 色 |
| 構造 | ページ・ナビ・面 | 無彩色 | 近黒 `#14151A` / 白 / グレー階調 |

属性色は赤・緑・青を占有しており、七瀬陸（赤）や二階堂大和（緑）を同じ強さで置くと「Shout なのか陸なのか」が判別できなくなる。色相の追加では解けないため、形で分離する。**キャラ色は面を塗らず、線・縁・小さな点にのみ使う。テキスト色への使用は禁止**（キャラ名は近黒のまま、色はスパインが担う）。

### 2. indigo を廃止し、クロームだけでなくリンク・見出し・ボタンも無彩色にする

クロームを近黒 `#14151A` にし、サイト内で意味を持つ色をキャラ 16 色と属性 3 色だけにする。副次的な利点として、彩度の低いキャラ色（八乙女楽のグレー、棗巳波のベージュ等）は白背景では弱いが、近黒の上では 16 色すべてが明確に分離する（§4 の実測値）。

**実装着手後に判明した点**: 当初はクローム（ヘッダー等の構造材）だけを無彩色化する想定だったが、`indigo` は 179 箇所で使われており、うち 106 箇所は `text-indigo-*`、すなわちリンクと見出しの色だった。クロームだけを無彩色にしても、サイトの主色はデフォルト色のまま残ってしまうため、リンク・見出し・主ボタン・フォーカスリングも無彩色化した。

- リンク: 近黒 + 下線
- 見出し: 近黒
- 主ボタン: 近黒の塗り
- フォーカスリング: 近黒

これにより「意味を持つ色はキャラ 16 色と属性 3 色だけ」という原則が例外なく成立する。

### 3. 署名要素: 16 色バーを 3 つのスケールで反復する

同じ 16 色の並びを異なるスケールで繰り返すこと自体をサイトの署名とする。ヘッダー下端の 3px 線（全ページ・ロゴ相当）、衣装一覧のキャラクターフィルタ（名前つきチップ、既存 `CardFilterChips` に色を付与、構造は変えない）、ホームのヒーロー（大判、各セグメントがそのキャラの衣装一覧へリンク）の 3 スケール。

いずれも**ユニット（IDOLiSH7 / TRIGGER / Re:vale / ŹOOĻ）で区切る**。16 色を単純に並べると近い色相が隣接し判別できないが、ユニット内では色がよく分離しているため。一覧のフィルタでは色だけでなくキャラ名も表示する（色は索引、名前はラベル。支援技術・キャラ色を知らない利用者への配慮）。大きな色面はホームのヒーローのみとし、他ページに色面を追加しない。

### 4. キャラクターカラーの色値と単一情報源

公開されている公式カラーコードは存在しないため、定着している色名から本設計で校正した候補 HEX を採用した（`src/lib/constants.ts` の `CHARACTER_HEX` を単一情報源とする）。

**コントラスト実測（WCAG 相対輝度）**:

- 16 色すべてが近黒 `#14151A` に対して 3:1（WCAG 1.4.11 非テキストコントラスト）以上を満たす。最小は和泉一織の 3.15、次点は狗丸トウマの 3.31
- 白 `#ffffff` に対する最小は千の 1.41（ほかに亥清悠 1.66・棗巳波 1.72・六弥ナギ 1.63・九条天 1.89・四葉環 1.99 が 2:1 未満）。**16 色は白背景では成立せず、近黒クロームが前提条件**であることが実測で裏付けられた

### 5. 数字・欧文専用フォントを導入する

CJK はシステムフォントスタックを維持する（ADR 0046 §5 を踏襲）。数値表示（スコア・属性値・パーセント・レベル）とラテン文字にのみ Barlow Semi Condensed（400 / 600 / 700）をセルフホストで適用する。日本語本文には適用しない。フォント資産は woff2 3 ファイル計 21,528 バイト。これは ADR 0046 §5「カスタム Web フォントは導入しない」に対する限定的な例外である。

## 適用範囲

色を出す場所: 衣装一覧の行スパイン、衣装詳細（キャラクター行のドット）、デッキスロット（スロット縁のマーカー）、キャラクターフィルタ、ヘッダーおよびホームの 16 色バー。

色を出さない場所: 本文の背景（`surface-card` = 完全不透明を維持）、テキスト色、上記以外の大きな色面。

**実装着手後に判明し、適用範囲を当初設計から変更した点:**

- **衣装比較のチャートは対象から外した。** `ShrinkChart.svelte` の系列枠線は既に属性色（`ATTR_HEX`）が占有しており、キャラ色を重ねると「属性＝塗り／キャラ＝線」の分離規則を自ら破ることになるため
- **`SharedBroachEditor`（共通ブローチ）にはメンバー色の縦帯を適用しなかった。** 当初はユニット別セクションだと想定していたが、実際には**ブローチの属性区分**（ALL / Shout / Beat / Melody / 条件付き）でグループ化されており、キャラのユニットではなかった。Shout/Beat/Melody は `ATTR_HEX` と厳密一致で既に規約準拠のため維持し、唯一恣意的だった配色（`条件付き` の purple）のみ無彩色化した
- **マーカーの形は場所によって 2 種類にした。** 衣装一覧の行・モバイル・タイルは縦長のピル（`border-top` のみのため問題なく成立）。デッキスロットは 4 辺が閉じた角丸ボーダーの箱で、平行な線同士が Gestalt の連続性により 1 本に見えてしまうため、角から対角に離したドットに変更した
- **フィルタチップの文字色は 3 通りにした。** 16 色は明度がばらばらで WCAG AA（4.5:1）を一律には満たせないため、既定は近黒文字、明度の高い 3 色は白文字、残る 2 色は原色を 88% に希釈した上で近黒文字とした

## 検討した代替案

- **グループ 4 色（IDOLiSH7 / TRIGGER / Re:vale / ŹOOĻ）を主役にする**: 変更規模が小さく安全だが、固有性が限定的で「個性がない」への回答にならない
- **1 画面 1 キャラ色（衣装詳細・キャラ絞り込み時のみ色が出る）**: 混乱リスクは最小だが、主戦場である一覧画面が現状のまま変わらず「地味」が残る
- **indigo を継承したままキャラ 16 色を追加する**: ブランド継続性は保たれるが、サイトの主色がデフォルト色のままとなり、色がアイドリッシュセブンの語彙にならない
- **キャラ色を塗り（面）で使う**: 視認性が高く目を引くが、属性色との衝突が解けず、淡色キャラでコントラストが破綻する（[ADR 0001](0001-reject-glassmorphism-redesign.md) の再演）

## 影響

- [0046](0046-apple-design-redesign.md) の §1（クロームの indigo 材）と §5（カスタム Web フォントを導入しない）を部分的に上書きした（0046 側に追記済み）
- `CLAUDE.md` のデザイン規約節を更新し、色の 3 チャンネル分離・キャラ色は面を塗らない・indigo 廃止を明記した
