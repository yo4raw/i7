# 0044 仕様解説ページ §4 に期待カバー率の明示と縮小 vs スコアアップ戦略比較を追加

- ステータス: 承認
- 日付: 2026-07-07

## 文脈

仕様解説ページ（ADR 0043）の §4 判定縮小について「縮小のスコア寄与（+294,534）が異様に低く見える」との指摘があった。調査の結果、計算エンジンは正しい（MC 平均と整合、ライト倍率も対象素点合計に織り込み済み）が、ページの見せ方に問題があると特定した:

- §4-3 は「全発動カバー率 100%（キャップ済み）」を表示する一方、§4-4 の期待値は「発動確率 per を織り込んだ期待カバー率 66.74%」で計算されており、その 66.74% がページのどこにも表示されていない。読者が 100% を式に代入すると表示値より約 36% 高い値になり、期待値が不当に低く見える
- また、スコアアタックの基本戦略（縮小カバー率 100% 以上の確保が先、スコアアップ全発動は上乗せ）とその根拠（縮小はスコアアップの約 2〜3 倍/枚の寄与で、属性値に比例して伸びる）がページに存在しなかった

## 決定

1. §4-3 のカバー率図を **2 段バー化**し、「全発動カバー率（100% キャップ）」と「per 織り込みの期待カバー率」を図で区別して見せる
2. §4-4 の数値例を「全発動なら +441K / 期待値では 66.7% → +294K」の **2 段構成**にし、数値の飛躍を解消する
3. §4-5「スコアアタックでの位置づけ」を新設し、(a) 基本戦略のコールアウト、(b) **1 枚あたり寄与の横棒比較図**（縮小 ≈ スコアアップの約 2〜3 倍/枚）、(c) **属性値スケーリング線グラフ**（縮小 = 素点比例で伸びる / スコアアップ = 固定値で水平）を置く
4. 数値はすべてビルド時に実エンジンから生成する（ADR 0043 の数値直書き禁止を維持）。全発動時の縮小上乗せはエンジン側から取得し、按分式の二重実装をしない

## 検討した代替案

- **§4-4 の本文加筆のみ（図は現状維持）**: 違和感の根本が「2 種類のカバー率が図で区別されないこと」のため、図の 2 段化まで行う案を採用
- **§4-3 図の分母を実効秒数（先頭除外控除後）へ変更**: 表示と実装の完全一致にはなるが、「先頭除外の秒換算」の概念が図に入り複雑化する。実装詳細 `<details>` に既に記載があるため不採用
- **デッキ合計の積み上げバーで縮小優位を見せる**: デモ編成はスコアアップ 4 枚 vs 縮小 2 枚で合計がほぼ同値になり優位が見えないため、「1 枚あたり」「属性値スケーリング」の比較軸を採用
- **期待値モデル自体の見直し（ライト倍率の位置相関の織り込み）**: エンジンは MC シミュレーションと整合しており正しいと確認できたため変更しない
