# 0082: イベント詳細の特効パネルを折りたたみ可能にする

- 日付: 2026-09-08
- ステータス: 承認

## 背景

イベント詳細ページ (`/events/{id}/`) は金・銀・銅の特効パネルを常に展開して並べている。銀特効は数十枚、銅特効は 100 枚近くになるイベントがあり、ページが縦に非常に長い。ADR 0081 で末尾に「対象楽曲」セクションを足したことで、そこへ到達するまでのスクロール量がさらに増えた。

見たい段階（多くの場合は金特効）だけを開いて、残りを畳めるようにしたい。

## 決定

`EventBonusCardGrid` の中身を **HTML の `<details>` / `<summary>`** で包み、パネル単位で折りたたみ可能にする。

- `<summary>` は既存の見出し行（段階バッジ + 「対象 N 枚 ・ 所持 M 枚」）をそのまま使う。**畳んだ状態でも対象枚数と所持枚数は読める**
- 既定は `open`。従来の見え方を変えない
- 開閉表示は `group-open:rotate-180` のシェブロンで示す。`ScoreCalc.svelte` の既存の `<details>` パターンに合わせた
- 開閉状態は保存しない（リロードで既定に戻る）

## 検討した代替案

- **JS で開閉状態を持つ独自アコーディオン** — キーボード操作・`aria-expanded`・検索時の自動展開を自前で実装することになる。`<details>` はそれらをブラウザが担保するため不採用
- **銀・銅を既定で畳む** — 「特効衣装の一覧を見に来た」利用者に対して、初見で情報が隠れる。既定は現状維持とし、畳むかどうかは利用者に任せる
- **開閉状態を localStorage に保存** — キー追加（`STORAGE_KEYS`・バックアップ対象）に見合うだけの要望が今はない。必要になってから足す
