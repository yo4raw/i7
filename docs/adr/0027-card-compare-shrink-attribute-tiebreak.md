# 0027: 衣装比較 判定縮小タブの属性値タイブレーク化とカバー率用語統一

- 日付: 2026-06-22
- ステータス: 承認

## 背景

[0016](0016-card-compare-shrink-coverage.md) で判定縮小タブの比較軸をカバー秒数（最大／期待）の一本軸に変更し、[0017](0017-card-compare-shrink-attr-reference.md) で属性値由来スコアを「参考表示（順位には影響しない）」として併記した。

しかし運用上、縮小衣装は属性値も含めて評価したいという要望があり、同時に2つの問題が顕在化していた。

1. **属性値が並び順にほぼ効かない**: カバー率（曲固定なら秒数と等価）が完全一致したときのタイブレークにしか属性値が使われていなかった。
2. **タイブレークと表示で属性値の定義が食い違っていた**: 表示（チャート脚注・詳細パネル）は選択曲での属性値由来スコア (`baseScore`) を出していたのに対し、ソートのタイブレークは曲非依存の属性値合計 (`appealTotal`) を使っていた。多色拮抗曲では両者がズレ、「表示と並びが合わない」状態だった。

また、ソート項目のラベルが「カバー秒数」だが、チャート縦軸・詳細パネルは実際にはカバー率(%)で表示しており、用語がねじれていた。

## 決定

1. **判定縮小タブのソートのタイブレークを `appealTotal` から `baseScore`（選択曲での属性値由来スコア）へ変更する。** これにより辞書式は「カバー率（最大／期待）→ 属性値由来スコア」の2段となり、表示の「属性」値と並び順の定義が一致する。発動確率は期待カバー率に畳み込み済みのため中間キーには加えない。
2. **ユーザー可視テキストの用語を「カバー率」に統一する。** ソートドロップダウン・詳細パネルの行ラベル・チャート棒下ラベル・チャート脚注・ページ説明文の「カバー秒数」表現を「カバー率」に揃える。詳細パネルおよびチャート棒下の表示値は「P% (Ns)」（率を主・秒数を括弧）に変更する。曲を全衣装で固定するためカバー秒数とカバー率は比例し、並び順そのものは変わらない。
3. これに伴い [0017](0017-card-compare-shrink-attr-reference.md) の「属性値由来スコアは順位に影響しない」という位置づけを更新し、同率時の並び順に反映されるものとする。

内部識別子 (`maxCoverSec` / `expectedCoverSec`) と `CardStrengthEntry` のデータ構造は変更しない（CLAUDE.md の用語ポリシー: 内部識別子は維持、ユーザー可視テキストのみ変更）。

## 検討した代替案

- **属性値由来スコアを独立したソート軸として選択肢に追加** — 縮小衣装はカバー率で並べるのが本筋であり、属性値は同率内の決定に効けば足りるため、軸の追加はせずタイブレーク強化に留めた。
- **縮小を期待上乗せスコアに換算し属性値と合算した単一スコアで並べる** — [0007](0007-card-compare-page.md) / [0016](0016-card-compare-shrink-coverage.md) が「縮小の単一数値化はしない」と明確に否定済みのため不採用。
- **発動確率を中間キーに入れる3段辞書式** — 期待カバー率に確率が畳み込まれており効く差分が限定的なため、シンプルな2段に留めた。
- **ソートラベルのみ率に変え詳細パネルは秒数のまま** — サイト内で用語が割れるため、可視テキストは率に統一した。

設計の詳細は [docs/superpowers/specs/2026-06-22-card-compare-shrink-attribute-tiebreak-design.md](../superpowers/specs/2026-06-22-card-compare-shrink-attribute-tiebreak-design.md) を参照。
