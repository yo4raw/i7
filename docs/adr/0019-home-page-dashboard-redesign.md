# 0019: トップページをダッシュボード型へフルリデザイン

- 日付: 2026-06-15
- ステータス: 承認

## 背景

機能追加（衣装比較・編成組合計算・共通ブローチ等）が続いた結果、トップページ `src/pages/index.astro` の「主な機能」セクションが現状の機能を反映できていなかった（衣装比較・編成組合計算・共通ブローチの3機能がカードに無い）。あわせてページ全体を現状機能に即した構成へ刷新する。

## 決定

トップページをダッシュボード型レイアウトでフルリデザインする。

- カードは「シンプル＋左アクセントバー」のソリッドカード。半透明・グラスは使わず、ソリッド背景＋ダークバリアントをペア指定（[0001](0001-reject-glassmorphism-redesign.md) のグラスデザイン視認性破棄の教訓を踏襲）
- セクション構成: ヒーロー（サイト名＋一言＋統計バッジ）→ 開催中／次回イベント（既存 `EventCountdown` 流用）→ 主な機能（ナビ構成に沿った3カテゴリ: データベース／スコア計算ツール／登録・管理）→ 衣装内訳 → 下部情報（謝辞・お問い合わせ・プライバシー・免責、全文維持）
- 機能カードに **衣装比較・編成組合計算・共通ブローチ** を追加し、全機能を網羅
- 既存のデータ取得ロジック・`EventCountdown` は流用し、UI のみ刷新

## 検討した代替案

- **機能カードの追加・整理のみ（最小変更）** — ユーザー希望によりフルリデザインを選択
- **クイックランチ型 / 縦長セクション型レイアウト** — ビジュアルコンパニオンで比較し、スキャンしやすいダッシュボード型を採用
- **アイコンチップ付き / カテゴリ色分けカード** — 視認性最優先のためシンプル＋アクセントバーを採用

設計の詳細は [docs/superpowers/specs/2026-06-15-home-page-dashboard-redesign-design.md](../superpowers/specs/2026-06-15-home-page-dashboard-redesign-design.md) を参照。
