# 0018: 衣装比較 スコアアップタブに最大値を重ね、期待/最大ソートを追加

- 日付: 2026-06-15
- ステータス: 承認

## 背景

[0016](0016-card-compare-shrink-coverage.md) で判定縮小タブは期待カバー秒数（発動確率込み）と最大カバー秒数（100%発動）を2段積みで重ね、期待／最大のソートを選べるようにした。

一方スコアアップタブは「属性値由来スコア + スキル期待値」の2段積み・期待値合計の降順のみで、スキルの最大値（100%発動時の上振れ上限）が見えなかった。縮小タブと操作・見え方を揃え、上振れ上限も比較できるようにする。

## 決定

スコアアップタブを判定縮小タブと対称な構成にする。

- **スキル最大値** = `最大発動回数 × スキル値`（確率を掛けない、100%発動時）を新たに算出
- **最大スコア合計** = `属性値由来スコア + スキル最大値`
- チャートの棒を3段積みにする: 属性値由来スコア（青・実体）／スキル期待値（濃い橙・実体）／スキル最大値−スキル期待値（薄い橙・上乗せ＝発動率による目減り）
- 上部ラベルにソートキーの値、各棒の補助ラベルに期待・最大の両方を併記
- ソートセレクタを追加: 期待スコア合計 / 最大スコア合計（既定=期待）。縮小タブの `compareShrinkBy` と対になる `compareScoreUpBy(key)` を新設
- 詳細比較パネルに「スキル最大値」「合計（最大）」行を追加

## 検討した代替案

- **表示の重ね合わせのみ（ソート・ラベルは現状維持）** — 縮小タブと操作が揃わず、最大値で並べ替えて上振れ上限を比較する価値も活きないため不採用
- **最大値を別の棒・別タブで表示** — 期待と最大は同一衣装の上下限であり、1本の棒に重ねる方が直感的なため不採用

設計の詳細は [docs/superpowers/specs/2026-06-15-card-compare-scoreup-max-overlay-design.md](../superpowers/specs/2026-06-15-card-compare-scoreup-max-overlay-design.md) を参照。
