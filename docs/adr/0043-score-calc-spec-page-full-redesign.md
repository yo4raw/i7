# 0043 スコア計算 仕様解説ページをパイプライン全体解説へ全面リデザイン

- ステータス: 承認
- 日付: 2026-07-07

## 文脈

`/score-calc/spec/` は判定縮小スキルの内部ロジック解説に特化しており（全 6 章中 5 章が縮小関連）、チーム属性値・センタースキル・ブローチ・ライト倍率・スコアアップスキル・最終補正といった実装済みロジックの大半が解説されていなかった。ユーザーから「実装しているロジックを SVG を使ってわかりやすいページに書き直してほしい」との要望があった。

## 決定

1. `/score-calc/spec/` を**スコア計算パイプライン全体**（全体像 → チーム属性値 → 1ノーツ素点 → スコアアップ → 判定縮小 → 最終補正 → 理論値/期待値/MC の 7 章）を解説するページへ全面リライトする
2. 章立ては**パイプライン縦断型**（計算の流れ順）とし、1 ページ縦置き + 目次ナビで構成する
3. 全章で**共通のデモ編成**（fixtures の実在衣装 6 枚 × MONSTER GENERATiON）を使い、数値例はビルド時に実エンジン関数を呼んで生成する（文中への数値直書き禁止）
4. 本文はプレイヤー向け平易記述、式・内部変数名・floor タイミングは各章の `<details>`「実装詳細」に収容する **2 層構造**とする
5. SVG は段階別配色（属性値=indigo / 素点=sky / スコアアップ=amber / 縮小=orange / 最終補正=emerald）・floor マーカー・現在地ハイライト付き俯瞰図の**統一ビジュアル言語**で `specDiagrams.ts` を全面リライトする。既存の縮小解説図・ShrinkPlayground も新規約に合わせて作り直す
6. 動的要素は静的 SVG 中心とし、インタラクティブ playground は縮小章のみに置く

## 検討した代替案

- **既存の縮小特化構成の改善に留める**: 実装ロジックの大半が未解説のままになるため不採用
- **実例トレース型（手書き数値のストーリー）のみ**: マスターデータ更新で数値が古びるため、ビルド時計算に置き換えて章立てへ統合
- **リファレンス辞書型 / 章ごとのサブページ分割**: 計算全体の繋がりが伝わらない・ナビゲーション複雑化のため不採用

## 影響

- `src/lib/score/specDemo.ts` 新設（`tests/fixtures/` をビルド時 import。デモ衣装 ID が fixtures から消えた場合はビルド失敗として検出する）
- `specDiagrams.ts` / `spec.astro` / `ShrinkPlayground.svelte` 全面書き換え、関連テスト更新
- 詳細設計: `docs/superpowers/specs/2026-07-07-score-calc-spec-redesign-design.md`
