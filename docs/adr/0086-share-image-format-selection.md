# 0086: 共有画像の保存形式を PNG / JPG / WebP から選べるようにする

- 日付: 2026-09-09
- ステータス: 承認

## 背景

イベント SNS 共有・衣装比較共有・スコア計算の画像保存（ADR 0023 / 0083 / 0084）は `modern-screenshot` の `domToPng` で PNG 固定だった。衣装 16 着のパネルを scale 2 で書き出すと 1 枚あたり数 MB になり、SNS やチャットに貼る用途では重い。

## 決定

- **保存形式を PNG / JPG / WebP の 3 つから利用者が選ぶ**。ダウンロードボタンの横に `<select>` を置く
- **既定は PNG**。従来の挙動と既存の E2E を変えない
- **非可逆形式（JPG / WebP）の品質は 0.8** に固定する。品質スライダーは置かない
- **選択は `i7_share_image_format` に保存し、全共有画面で共有する**。画面ごとに選び直させないため。バックアップ対象に含める
- 描画は `domToDataUrl` に `type` / `quality` を渡す 1 本のヘルパー（`src/lib/shareImage.ts`）に集約し、各画面の `domToPng` 直呼びをなくす

## 検討した代替案

- **JPG に一本化する** — 容量は減るが、透過は使っていないものの細い線や小さい文字が滲む。用途で選べるほうがよい
- **WebP に一本化する** — 主要ブラウザは対応済みだが、貼り付け先のサービスが WebP を受け付けない場合がある
- **画面ごとに形式を保存する** — 用途が同じ（SNS 共有）なので分ける理由がない
- **品質を選べるようにする** — 選択肢が増えるだけで、0.8 で見た目上の差はほぼ出ない
