# 0017: 衣装比較 判定縮小タブに属性値由来スコアを参考表示

- 日付: 2026-06-15
- ステータス: 承認

## 背景

[0016](0016-card-compare-shrink-coverage.md) で判定縮小タブの比較軸をカバー秒数／カバー率に再設計した際、旧版チャートにあった属性値の表示が落ち、縮小タブに各衣装の属性値がまったく出ない状態になっていた。

縮小衣装もデッキに編成されるため自身の属性値でスコアに寄与する。比較は基本的にカバー率で行うが、曲の属性が多色で拮抗している場合は、どの縮小衣装がその曲でより多くスコアを稼ぐかが選択の参考になる。

## 決定

判定縮小タブのチャートに、各衣装の**属性値由来スコア**（選択曲のノーツ配分を反映した `baseScore`）を参考値として表示する。

- 表示値は曲非依存の単純合計（Shout+Beat+Melody）ではなく、曲のノーツ配分を反映した属性値由来スコア。多色拮抗曲での寄与を直接比較でき、スコアアップタブとも軸が揃うため
- **ソートには影響させない**。比較の主軸はカバー率（期待・最大）のままで、属性値由来スコアはあくまで参考表示

## 検討した代替案

- **属性値合計（3属性の単純合計）を表示** — 曲の属性配分を反映せず多色拮抗曲の参考にならないため不採用
- **属性値をソート軸に昇格** — カバー量（秒）と属性スコア（点）は単位が異なり統合が困難。比較の主目的はカバー率であり参考表示で十分なため不採用

設計の詳細は [docs/superpowers/specs/2026-06-15-card-compare-shrink-attr-reference-design.md](../superpowers/specs/2026-06-15-card-compare-shrink-attr-reference-design.md) を参照。
