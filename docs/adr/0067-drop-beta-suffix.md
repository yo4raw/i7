# 0067 サイト名から (β) を外す

- ステータス: 承認
- 日付: 2026-09-02

## 文脈

サイト名は公開当初から `i7マネ部屋(β)` としてきた。まだ機能が揃っておらず、データの正確性も検証途上だった段階で、「試験公開である」と利用者へ断るための表記だった。

現時点の状況は次の通り。

- 衣装 2,850 枚・楽曲 149 曲・イベント 88 件のマスターデータが揃い、毎時の cron で自動更新されている
- スコア計算・所持衣装管理・特効衣装一覧・編成組合計算・ポイント芸計算といった主要ツールが実装済みで、単体テスト（Vitest）と E2E（Playwright）で継続的に検証している
- Cloudflare Workers への自動デプロイとタグの自動採番が確立し、リリースが定常運用になっている

一方で `(β)` を残し続けることには次の問題がある。

- **表記が実態と合っていない**。「まだ動かないかもしれない」という予告として読まれるが、実際には定常運用されている
- **正式名称が定まらない**。ヘッダー・PWA の `name`・OGP・llms.txt・README で同じ文字列を使っており、`(β)` 付きが事実上の正式名称として外部に流通してしまう
- **外すタイミングが自然には来ない**。β を明示的に終わらせる決定をしない限り、惰性で残り続ける

## 決定

**サイト名を `i7マネ部屋` とし、`(β)` を全面的に削除する。**

`(β)` は「試験公開」の意思表示であり、機能・データ・運用のいずれも定常段階に入った以上、表示を実態に合わせる。

非公式ファンサイトである旨の断り書き（`/about/` の免責事項・ホームの注意書き）はそのまま維持する。`(β)` が担っていたのは「開発途上」の告知であって「非公式」の告知ではないため、両者を混同しない。

### 適用範囲

サイト名を表示・宣言しているすべての箇所から `(β)` を外す。

| 箇所 | 内容 |
| ---- | ---- |
| `src/lib/constants.ts` の `SITE_NAME` | ヘッダー・`<title>`・OGP の単一情報源 |
| `public/manifest.webmanifest` の `name` | PWA のインストール名 |
| `public/llms.txt` の見出し | LLM 向けのサイト説明 |
| `public/sw.js` の冒頭コメント | 実害はないが表記を揃える |
| `src/pages/about/index.astro` | 「当サイト「…」は」の本文 |
| `README.md` の見出し | リポジトリの説明 |

`src/lib/seo.ts` の各 description と `BaseLayout.astro` の `apple-mobile-web-app-title` は元から `(β)` を含まないため変更しない。`docs/` 配下の過去の設計メモは当時の記録として残す。

あわせて `public/sw.js` の `SW_VERSION` を `v3` → `v4` に上げる。`manifest.webmanifest` は `APP_SHELL` として `i7-static-v3` にキャッシュされており、バージョンを上げないと既にインストール済みの PWA が旧名のまま残るため。

## 検討した代替案

- **`(β)` を残す**: 変更コストはゼロだが、実態と表記の乖離が続く。外す判断を先送りしても状況は変わらない
- **`(beta)` や「ベータ版」など別表記に置き換える**: 表記の問題ではなく、β 段階そのものを終わらせる決定なので意味がない
- **バージョン番号（`v1.0`）を名前に含める**: リリースタグは自動採番で頻繁に上がるため、名前に含めると更新のたびに乖離する。サイト名は不変にし、バージョンは `/releases/` で示すのが適切
- **`SW_VERSION` を上げない**: 新規訪問者には新しい名前が出るが、PWA をインストール済みの利用者には旧名が残る。名前を変える決定と矛盾する

## 影響

- 上記 6 ファイルの文字列を変更する。ロジックの変更はない
- `SW_VERSION` を上げるため、既存利用者の static キャッシュが 1 度だけパージされる（初回アクセスが再取得になる）
- サイト名を検証しているテストは存在しないため、テストの修正は不要
