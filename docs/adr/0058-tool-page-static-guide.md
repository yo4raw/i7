# 0058 ツールページに静的な解説セクションを置く

- ステータス: 承認
- 日付: 2026-08-21

## 文脈

[0057](0057-focus-indexable-pages.md) で、インデックス対象を独自性のあるページへ絞った。その過程で、**インデックスさせたい本命ページが、インデックスされる条件を満たしていない**ことが判明した。

各ツールページは `client:only="svelte"` のクライアントサイドアプリで、静的 HTML にはタイトルとナビゲーションしか無い。

| ページ | 静的テキスト量 |
| --- | --- |
| スコア計算 | 118 文字 |
| 衣装比較 | 210 文字 |
| ポイント芸計算 | 200 文字 |
| 編成組合計算 | 8,258 文字 |

このサイトの独自価値はデータベースではなくツールであり（衣装データは既にインデックス済みの `i7.step-on-dream.net` 由来）、検索から入る価値があるのはツールページである。にもかかわらず、Google に提示できる内容が実質ゼロだった。

一方で `score-calc/spec`（スコア計算 仕様解説、14,554 文字）は完全独自コンテンツとして機能している。ツールページにも同種の実体を持たせる必要がある。

## 決定

**各ツールページの下部に、ビルド時に出力される静的な解説セクションを置く。**

共通コンポーネント `src/components/seo/ToolGuide.astro` を用意し、次の 4 区画を持たせる。

| 区画 | 内容 |
| --- | --- |
| このツールについて | 何をするツールかの要約（1〜2 文） |
| 使い方 | 番号付きの手順 |
| 計算の前提と注意点 | 計算の根拠・制約・免責 |
| よくある質問 | 利用者が実際に迷う点 |

### 内容はツールの実挙動の説明に限る

**検索対策の水増しは書かない。** キーワードを詰め込んだ文章ではなく、実際に使う人が読んで役に立つ説明だけを置く。判定縮小の按分、カバー率が 100% にならない理由、期待値と理論値とシミュレーションの違いなど、**ツールを使う上で実際に疑問になる点**を扱う。結果としてこれが独自コンテンツになる。

### 配置はツールの下

ツール本体を押し下げないよう、解説はツールの後ろに置く。ツールを使いに来た利用者の導線を損なわない。

### ツールの仕様を変えたら解説も更新する

解説とツールの実挙動が食い違うと、利用者を誤らせるうえに検索評価上も逆効果になる。`ToolGuide.astro` のコメントと `CLAUDE.md` に明記する。

## 結果

| ページ | 変更前 | 変更後 |
| --- | --- | --- |
| スコア計算 | 118 文字 | 1,273 文字 |
| 衣装比較 | 210 文字 | 1,250 文字 |
| ポイント芸計算 | 200 文字 | 1,094 文字 |
| 編成組合計算 | 8,258 文字 | 9,333 文字 |

## 検討した代替案

### ツールを SSR して静的 HTML に出力する（却下）

`client:only` をやめて初期状態をサーバーレンダリングすれば静的テキストは増えるが、出力されるのは空のフォームとプレースホルダであり、読み物としての価値は無い。検索エンジンにとっても利用者にとっても意味のあるコンテンツにはならない。加えて、ADR 0046 の「完全静的サイト」方針のもとでビルド時間とハイドレーション不整合のリスクだけが増える。

### `score-calc/spec` のような独立した解説ページを各ツールに作る（見送り）

ページ数は増やさず、ツールページ自体の価値を上げるほうが筋がよい。解説を別ページに切り出すと、ツールページ本体は空のままで問題が解決しない。分量が増えて独立した読み物になった時点で切り出しを再検討する。

### FAQ の構造化データ（FAQPage JSON-LD）を入れる（見送り）

Google は 2023 年以降、FAQ リッチリザルトの表示を政府・医療系サイトに限定している。一般サイトでは表示されないため、実装コストに見合わない。

## 影響

- `src/components/seo/ToolGuide.astro` を新設。
- `src/pages/score-calc/index.astro`、`src/pages/score-calc/max-score-finder/index.astro`、`src/pages/card-compare/index.astro`、`src/pages/point-calc/index.astro` に解説を追加。
- `tests/seo.test.ts` に、各ツールページで解説セクションが出力されることを検証するテストを追加。
- `CLAUDE.md` に「ツールの仕様を変えたら `ToolGuide` の内容も更新する」旨を追記。

## 残る課題

- **被リンクが無い。** 無名ドメインの信頼は外部リンクでしか付かない。本 ADR も 0057 も、被リンクの代わりにはならない。ツールまとめサイトへの掲載や X での告知が本質的な解決になる。
