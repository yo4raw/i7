# 0016: 衣装比較 判定縮小タブの比較軸をカバー秒数／カバー率へ変更

- 日付: 2026-06-15
- ステータス: 承認

## 背景

[0007](0007-card-compare-page.md) で新設した衣装比較ページの判定縮小タブは、効果秒数（1発動あたりの縮小秒数）を最優先する多段ソート（効果秒数 → 最大発動回数 → 確率 → 属性値）で全衣装を並べていた。

しかし判定縮小衣装の実価値は「1発動あたりの秒数」単独ではなく、**曲全体でどれだけの時間を縮小で覆えるか**で決まる。コンボ／パーフェクトタイプの効果秒数は主にスコア期待値の上昇に寄与する要素であり、縮小衣装同士の比較で本質的に効くのは曲全体のカバー量である。効果秒数を独立した最優先キーにする辞書式は、この実態とズレていた。

## 決定

判定縮小タブの比較軸を、効果秒数優先の辞書式から **曲全体のカバー秒数** に一本化する。

- **最大カバー秒数 (A)** = `最大発動回数 × 縮小秒数`（100%発動前提の上限）
- **期待カバー秒数 (B)** = `A × (発動確率/100)`（発動確率込みの期待値）
- 最大発動回数 = `floor(発動機会 ÷ count)`（タイマー: 発動機会＝曲秒数 / コンボ・パーフェクト: 発動機会＝ノーツ数）
- **カバー率** = カバー秒数 ÷ 曲秒数。曲を全衣装で固定するため並び順はカバー秒数と一致し、独立したソート軸にはせずチャート縦軸とラベル併記に用いる
- ソートは A / B の2択（デフォルト B）。チャート縦軸はカバー率(%)、棒は2段積み（実体＝期待カバー率、薄い上乗せ＝最大−期待の発動率による目減り）、100%超は振り切れ表示
- 従来の「同率縦積み」は廃止

## 検討した代替案

- **効果秒数優先の辞書式を維持** — 1発動秒数の単独比較が実態とズレているため不採用（本 ADR で覆す対象）
- **A・B に加え効果秒数・確率・属性値も並べ替え軸に含める** — 今回の本題（カバー量での比較）に集中するため A・B のみに絞る
- **カバー率を独立したソート軸にする** — 曲固定のためカバー秒数と並び順が一致し冗長なので、表示のみに用いる

設計の詳細は [docs/superpowers/specs/2026-06-15-card-compare-shrink-coverage-design.md](../superpowers/specs/2026-06-15-card-compare-shrink-coverage-design.md) を参照。
