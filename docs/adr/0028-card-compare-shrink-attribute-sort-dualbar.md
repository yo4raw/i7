# 0028: 衣装比較 判定縮小タブに属性値由来スコア順ソートを追加しデュアルバー化

- 日付: 2026-06-22
- ステータス: 承認

## 背景

[0016](0016-card-compare-shrink-coverage.md) で判定縮小タブの比較軸をカバー率（最大／期待）に一本化し、[0027](0027-card-compare-shrink-attribute-tiebreak.md) で同率時のタイブレークを属性値由来スコア (`baseScore`) に統一した。

しかし縮小衣装を選ぶ際、「その曲でどれだけ属性値スコアを稼げるか」で並べたい場面がある。縮小スキルの価値はカバー率で測れるが、衣装自身の属性値スコアも編成全体のスコア土台に効くため、属性値由来スコアの高い順に見たいという要望が出た。あわせて、カバー率と属性値スコアを同時に視覚比較したいという要望もあった。

## 決定

1. **判定縮小タブのソートに「属性値由来スコア順」を追加し、初期選択をこれにする。** ソートキー `ShrinkSortKey` を `'attr' | 'max' | 'expected'` に拡張する。
   - `'attr'`（デフォルト）: `baseScore` 降順 → 同値は期待カバー率（`expectedCoverSec`）でタイブレーク
   - `'max'` / `'expected'`: カバー率降順 → 同値は `baseScore`（ADR 0027 のまま）
2. **チャートをデュアルバー化する。** 各衣装の列に縦棒を2本横並びにし、左＝カバー率（従来の2段積み: 濃い=期待／薄い=最大との差、100%超は▲）、右＝その曲での属性値由来スコア（表示中エントリの最大 `baseScore` を 100% とした相対高さ、別色）を同時に表示する。カバー率（率）と属性値スコア（点）は単位が異なるため、属性値バーは相対正規化する。
3. 表示範囲（所持のみ／全件トグル）・件数・状態の永続化は変更しない（ADR 0007 を踏襲し、毎回初期状態 `'attr'`）。

## 検討した代替案

- **属性値由来スコアを主キーに一本化（ドロップダウン廃止）** — カバー率での並べ替えも残したいため、選択肢追加の切替式にした。
- **属性値由来スコアを主キー固定でカバー率はタイブレークのみ** — 同上の理由で切替式の方が柔軟。
- **属性値バーをカバー率と同じ絶対軸で描く** — 単位が異なり共有軸にできないため相対正規化とした。
- **デュアルバーにせず属性値はラベルのみ** — 「カバー率の横に属性値を視覚的に並べたい」という要望に応えるためデュアルバーを採用。
