# 0022: 所持コレクションダッシュボードの追加

- 日付: 2026-06-16
- ステータス: 承認

## 背景

所持衣装ページ（`/mycard/`）には所持種類数・合計枚数の簡易サマリしかなく、収集の進捗（全UR中どれだけ集まったか、キャラ別・属性別の偏り）が把握できなかった。

## 決定

所持衣装ページ上部に **`CollectionDashboard.svelte`** を追加し、`i7_card_counts`（所持数ストア）と全カードデータからコレクション状況を可視化する。

表示内容（種類ベース。所持 = 枚数 > 0）:
- **総括**: UR 収集率（所持種類 / 全UR種類）・全レアリティ収集率・所持種類・合計枚数
- **レアリティ別収集率**: UR/SSR/SR/R/N の所持種類/全種類をバー表示
- **キャラクター別 UR 収集率**: グループ（IDOLiSH7 / TRIGGER / Re:vale / ŹOOĻ）ごとに各メンバーの所持/全 UR をバー表示
- **所持衣装の属性バランス**: Shout/Beat/Melody の所持種類をドーナツ（既存 `attrDonutSvg` 流用）

## 検討した代替案

- **専用ページ `/collection` を新設** — 所持衣装ページの延長として自然なため、新ページではなく既存ページ上部のセクションとして配置
- **枚数ベースの集計** — 同一カードを複数所持しても「収集率」としては種類ベースが妥当なため種類で集計（合計枚数のみ別途表示）
- **チャートライブラリ導入** — 既存の Tailwind プログレスバー＋`donutChart` で十分なため新規依存は導入しない
